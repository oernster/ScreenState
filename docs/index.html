Reboot or sign in. Your desktop arranges itself.

Every reboot, the same ritual: start the same applications, drag each window to the same display, maximise it, repeat. ScreenState does it for you. Capture your desktop once as a profile; from then on, signing in starts what was running and puts every window back on the display it belongs on.

How it works

Capture once. Restored after every reboot or sign-in.

  1. Capture. Arrange your desktop the way you like it and capture it. ScreenState lists every application with a window on screen and how many windows it has, recording where each one sits; untick anything you want left out, name the profile and save. An application running with no window shown is not offered: it has nothing to arrange. Nothing is written until you confirm.
  2. Mark a default. The default profile is the one applied after you sign in. With only one profile, it is the default.
  3. Sign in. ScreenState waits in the notification area, starts whatever the profile says should be running and places each window the moment it appears, without waiting for the slowest application. A message on every display says the desktop is being prepared, then that it is ready. Opening the manager takes that message down at once. Only a sign-in arranges the desktop by itself: starting ScreenState by hand opens the manager and moves nothing. Apply arranges a profile whenever you ask.
  4. Read what happened. If anything could not be done, the splash says how many applications did not start and the report, in the tray menu, names each one with the reason.

Supporting ScreenState

Free. It stays free.

There is no paid tier, no licence key and no feature held back behind a donation. If ScreenState has saved you the morning drag-and-maximise, a contribution supports its maintenance. The same link sits at the foot of the manager's button rail.
